ChatGPT 또는 Claude에서 AI 인터뷰 진행하기

  
이 단계부터 장소가 바뀝니다. 새 채팅을 열고, 준비한 자료를 넣은 뒤 대화를 시작하세요.

  
지금 하는 곳: ChatGPT 또는 Claude의 새 채팅

  


  

    
방법 A · 파일 업로드

      
1. 새 채팅을 엽니다.
2. concept-card.md와 선택한 prd-template.md를 첨부합니다.
3. 이 페이지의 한국어 Interview Prompt를 복사해 붙여넣습니다.
4. 전송합니다.

    

    
방법 B · 복사/붙여넣기

      
파일 첨부가 어렵다면 새 채팅에 Interview Prompt → Concept Card → PRD Template 순서로 붙여넣어도 됩니다.

    

  


  
중요: AI가 첫 답변부터 PRD 전체를 써버리면 멈추고 이렇게 말하세요.
“아직 PRD를 작성하지 말고, 먼저 중요한 결정을 위한 질문부터 해줘. 한 번에 3–5개만 물어봐.”


  
AI 질문에 답할 때

  

    
1. 편하게 답하기
전문용어를 쓸 필요 없습니다. “잘 모르겠다”, “A와 B 중 고민된다”도 좋은 답입니다.

    
2. 선택지는 비교시키기
모르겠다면 “가능한 선택지 3개와 각각의 장단점을 알려줘”라고 요청하세요.

    
3. 기술은 행동으로 설명하기
“Supabase가 필요해?” 대신 “사용자마다 자기 데이터만 보이게 하고 싶다”고 말하세요. 기술 번역은 AI에게 맡깁니다.

  


  
특히 C. Feature Implementation Spec을 골랐다면

  
AI가 database, authentication, API, hosting 같은 용어를 제안할 수 있습니다. 그 기술을 이미 알아야 하는 것은 아닙니다. “왜 필요한지 비전공자에게 설명해줘”, “더 단순한 대안은?”, “무료/초보자 친화적 선택은?”이라고 되물으세요. 기술 선택은 이 단계에서 확정 사실이 아니라 기능에서 도출된 구현 가설입니다.


  
대화가 충분히 진행되면

  
지금까지 내가 답한 내용을 바탕으로 핵심 제품 결정을 먼저 요약해줘.
1) 결정된 것
2) 아직 가정인 것
3) 열린 질문
을 구분해 보여줘.

내가 확인한 뒤에만, 제공한 PRD Template의 구조를 유지해서 최종 PRD를 작성해줘.
