이 웹페이지
7-1. Claude Code에 줄 3단계 한눈에 보기

    

      
1단계
전체 서비스 뼈대
One-Page PRD를 그대로 넣어 Next.js 웹 앱을 만듭니다. 외부 API와 Supabase는 “나중에 연결할 예정이니 지금은 하지 마”라고만 알리고, 샘플 데이터로 화면이 동작하게 합니다.

      
2단계
외부 API 연결 + Key 넣기
핵심 API 하나를 연결하고, 내가 API Key를 붙여넣을 .env와 .gitignore를 설정하게 합니다.
이제 실시간 가격을 가져오기 위해 Finnhub API를 연결할 준비가 됐어. API Key는 준비되어 있어. 내가 Key를 붙여넣을 수 있도록 .env 파일과 .gitignore를 설정해줘.

      
3단계
Supabase로 DB 연결
로그인과 데이터 저장을 붙이고, 사용자가 자기 데이터만 보게 합니다.
Supabase로 데이터베이스를 설정해줘. Supabase MCP는 연결되어 있어. 사용자가 로그인하고 관심 종목을 저장할 수 있게만 해줘. 사용자는 자기 종목만 볼 수 있어야 해.
